# Português

## 🔐 Smart Detector – Sistema de Detecção Inteligente de Ameaças em Aplicações Web

O **Smart Detector** é um sistema desenvolvido para exibir em tempo real eventos de possíveis anomalias detectadas por um IDS (Intrusion Detection System). Além do monitoramento, o sistema permite o armazenamento e consulta desses eventos, bem como gestão de usuários, controle de acesso e cadastro de LLMs utilizadas pelo IDS.

## 📌 Objetivos do Projeto
- Exibir eventos em tempo real provenientes de um IDS  
- Armazenamento e consulta futura dos eventos  
- Consulta detalhada  
- Gestão de usuários, perfis e permissões  
- Gerenciamento de LLMs

## 🎯 Escopo
✔️ Painel web em tempo real  
✔️ Armazenamento e consulta  
✔️ Gestão de usuários, LLMs e permissões  

## ⚙️ Tecnologias Utilizadas
- **Frontend**: Vue.js (2.7.16)  
- **Backend**: PHP 7.3.26 / Laravel 8.83.29  
- **Database**: MySQL (MariaDB 10.4.17)

## 🛡️ Funcionalidades
- CRUD de usuários  
- Perfis (Admin / Usuário)  
- JWT Auth + Logout  
- Eventos em tempo real  
- Filtros, paginação, detalhes  
- Gestão de risco, LLMs e tipos de ameaça  

## 📘 Documentação da API
🔗 https://github.com/juliofraga/smart_detector/wiki/Documenta%C3%A7%C3%A3o-da-API

# English

## 🔐 Smart Detector – Intelligent Threat Detection System for Web Applications

**Smart Detector** is a system designed to display real-time anomaly events detected by an IDS (Intrusion Detection System). It also supports event storage, querying, user management, access control, and LLM configuration for IDS usage.

## 📌 Project Objectives
- Display real-time IDS events  
- Store events for future querying  
- Detailed event inspection  
- User, role, and permission management  
- LLM management for the IDS

## 🎯 Scope
✔️ Real-time web dashboard  
✔️ Event storage & querying  
✔️ User, LLM, and permission administration  

## ⚙️ Technologies Used
- **Frontend**: Vue.js (2.7.16)  
- **Backend**: PHP 7.3.26 / Laravel 8.83.29  
- **Database**: MySQL (MariaDB 10.4.17)

## 🛡️ Main Features
- User CRUD  
- User roles (Admin / User)  
- JWT Auth + Logout  
- Real-time event feed  
- Filters, pagination, details  
- Risk classifications, LLMs, threat types
